# Aries skill library for every AI

Download the zip for the AI you use. Each one has a `SETUP.md` inside with the steps.

| AI | Download |
|---|---|
| Claude (claude.ai skill) | [aries-for-claude.zip](aries-for-claude.zip) |
| ChatGPT (custom GPT or Project) | [aries-for-chatgpt.zip](aries-for-chatgpt.zip) |
| Gemini (Gem) | [aries-for-gemini.zip](aries-for-gemini.zip) |
| Grok (Project) | [aries-for-grok.zip](aries-for-grok.zip) |
| Perplexity (Space) | [aries-for-perplexity.zip](aries-for-perplexity.zip) |
| Mistral Le Chat (Agent + Library) | [aries-for-mistral-le-chat.zip](aries-for-mistral-le-chat.zip) |
| DeepSeek, Meta AI, Copilot, any other chatbot | [aries-for-deepseek-and-others.zip](aries-for-deepseek-and-others.zip) |
| Claude Code | [aries-for-claude-code.zip](aries-for-claude-code.zip) |
| OpenAI Codex / AGENTS.md tools | [aries-for-codex.zip](aries-for-codex.zip) |
| GitHub Copilot | [aries-for-github-copilot.zip](aries-for-github-copilot.zip) |
| Cursor | [aries-for-cursor.zip](aries-for-cursor.zip) |
| Everything | [aries-skill-library-ALL-AIs.zip](aries-skill-library-ALL-AIs.zip) |

For coding tools (Claude Code, Codex, GitHub Copilot, Cursor), unzip that tool's zip into the root of your Aries checkout on your own computer when you want it. Nothing is installed in the repo itself, so the AI files stay in this folder.

The library covers: what Aries is, running and deploying it, the owner's guide, every crew agent's job, the agent engine, connectors, the API, testing, the web and Android apps, and launching/releasing.
